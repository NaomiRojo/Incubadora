Acerca de este espacio

Este espacio para eventos en el centro de la ciudad es perfecto para casi cualquier ocasión. Con una capacidad de hasta 200 personas, es ideal para cumpleaños, bodas, eventos corporativos y reuniones familiares. El salón cuenta con sistema de sonido de última generación, iluminación ambiental y una cocina totalmente equipada. También hay un amplio estacionamiento disponible para tus invitados.

El precio de alquiler del espacio es de $500 por hora o $3.000 por día completo. También se pueden armar paquetes personalizados según el tipo de evento, cantidad de invitados y servicios adicionales (decoración, catering, DJ, etc.). Contáctanos para recibir una cotización detallada.
